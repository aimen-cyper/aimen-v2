# سجل التغييرات

## 1.3.1 — مراجعة تحديث الحالة والتتبع (على 1.3.0)

**الترحيل:** `0013_order_sync_visibility` (إضافي بالكامل؛ الرجوع للكود القديم آمن). إعدادات 72 → 80. خدمات 18 → 19 (`order_messages`). مهام 12 → 13 (`orders_refresh_messages`). معالجات 158 → 159.

### إصلاحات (كل بند له اختبار انحدار فشل على 1.3.0 ونجح الآن — انظر `reports/regression_evidence/`)
- **المتابعة:** فاصل فحص الطلب النشِط لا يتباطأ إلى ساعة (كان 120→900→1800→3600 مرتبطاً بعدد الفحوص)؛ الآن 120→240→300 عند النجاح و60…600 عند الفشل بحسب عدد الإخفاقات المتتالية. نجاح فحص يمسح «تعذّر الاتصال» ويسجّل آخر فحص ناجح. جولة الفحص بميزانية زمنية وما لم يُفحص يُفرَج عنه.
- **قاطع الدائرة:** فشل **استعلام الحالة** لا يعطّل المزود ولا يرفض الطلبات الجديدة؛ يُنبَّه الأدمن مرة كل ساعة كحد أقصى.
- **الإلغاء والاسترجاع:** إلغاء الأدمن لطلب عند المزود لا يسترجع إلا بتأكيد «Canceled»؛ فشل الاستعلام ⇒ رفض بلا حركة مالية؛ «استرجاع قسري» زر منفصل بصلاحية وتدقيق؛ التدقيق ذرّي مع الاسترجاع (فشله يُسقط الاسترجاع كله).
- **مسار موحّد للحالة:** `admin_override_status` يمر عبر `_transition` (سجل تاريخ + إشعار + رسائل) ولم يعد يتجاوزه.
- **اتساق العرض:** بطاقة المستخدم تحسب المنفَّذ من `remains` (JAP لا يرسل `quantity`)، وتعرض «آخر تحديث» وزر «🔄 تحديث»؛ بطاقة الأدمن تعرض حالة المزود وآخر خطأ فحص؛ دالة مبالغ واحدة لكل الشاشات.
- **رسائل تيليجرام:** تأكيد الطلب/إشعار الإنشاء/منشور القناة تُعدَّل عند تغيّر الحالة؛ فشل التعديل لا يمس `orders.status`؛ منشور قناة التوثيق بلا وجهة يبقى بالطابور؛ إشعار الاسترجاع لا يُبتلع بعد فشل.
- **الإقلاع:** `run_polling(error_callback=…)` كان يفشل بـ`TypeError`؛ أُصلح عبر `error_handler`، و`Conflict` يصل إلى `ConflictGuard`.
- **الإشعارات:** جولة الإرسال بميزانية زمنية (25ث) وما تبقّى يعود للطابور فوراً (حدّ من تحذيرات «الحد الأقصى للنسخ الجارية»).
- **التسعير:** إزالة سعر الصرف الاحتياطي 530 من الكود؛ تنبيه الأدمن بالهامش السالب المتوقع بعد تغيير سعر الصرف؛ إعداد `block_negative_margin` (افتراضي `false`).

### إضافات
- `scripts/pricing_audit.py` (قراءة فقط) و`audit_ledger`: فحص «مُسترجَع رغم أن المزود أبلغ تنفيذه» + تنبيهات حساب التكلفة والاسترجاع الجزئي.
- «🗺 خريطة المزودين» (قراءة فقط) ومعاينة ربط رقم المزود قبل الربط.
- تنسيق مركزي للنصوص (بلا مسافات بادئة)، أسماء عربية لمجموعات الإعدادات، صفوف أزرار ≤ 3، و`docs/ADMIN_UI_PREVIEW.md`.
